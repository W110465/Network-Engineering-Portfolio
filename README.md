# Network Engineering Portfolio

## About This Portfolio

Welcome to my Network Engineering Portfolio.

This repository documents my hands-on experience designing, configuring, securing, and troubleshooting computer networks using physical Cisco networking equipment and network simulation tools.

My objective is to demonstrate practical networking skills through real configurations, verification commands, technical documentation, and structured troubleshooting.

## Technical Skills

- **Routing & Switching:** VLANs, inter-VLAN routing, static routing, and network connectivity
- **Network Services:** DHCP, DNS, NAT/PAT, and NTP
- **Network Security:** Port Security, DHCP Snooping, SSH, and access control
- **Troubleshooting:** Cisco IOS CLI, interface diagnostics, configuration recovery, and connectivity testing
- **Tools:** Cisco routers, Cisco switches, Cisco IOS, and Cisco Packet Tracer

## Projects

This portfolio will include documented projects covering:

1. Cisco Physical Home Network
2. SSH Remote Management
3. Switch Port Security
4. Router Startup Configuration Recovery
5. DHCP Snooping
6. NAT/PAT Configuration and Verification

Each completed project will include its objectives, topology, configuration steps, verification results, troubleshooting findings, and lessons learned.
